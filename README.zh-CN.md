# 深度学习开放问题集

这是一个研究深度学习本质机制与预测规律的社区问题库：记录已有解释、适用边界、尚未确定的部分，以及能推进理解的具体检验。纯粹的方法排名或模型选型不构成主线问题。

[筛选标准与重新审视的条目](docs/SCOPE.md)。66 条为历史检索线索，不是已认可的核心问题；066 已移出主候选队列并保留历史记录。

**正式候选目录保留三个问题；两轮检索累计 111 次查询、151 篇原始论文、66 条线索，其中 63 条是拟新增候选、3 条更新已有问题。[第二轮中文导览](discovery/2026-10-01-expansion/README.zh-CN.md) 新增 40 条，覆盖 24 个细分领域。均未完成全文审计。“候选”不等于确认无人解决。**

你可以贡献一个候选问题、一篇改变结论的论文、反例、复现结果、检索记录，或指出两个问题实际上等价。无需先写代码；Issue 支持中文与英文。正式条目以英文为主，便于国际协作。

每个问题只有一个永久 ID，但可以归属多个主题。理论、实证和预测能力分开描述；文献缺口与已复现的预测失败分开标注。已解决或合并的问题保留历史。

当前采用 MIT 许可开放原创文字和代码，外部论文及数据的许可不受影响。自动检查只检查格式和引用完整性，学术结论仍需人工审查。
