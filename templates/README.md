# Problem template

Copy the `problem` directory into `problems/DLOP-NNNN` and replace every placeholder. Read [contributing](../CONTRIBUTING.md) before assigning a provisional ID. A candidate may be incomplete scientifically, but must describe its uncertainty and include at least one relevant primary source.

Metadata stores identity, scope, evidence summaries and relationships. The README contains the scientific argument and directly linked citations. Keep the two consistent. Use `bibliography.json` source IDs in metadata and ordinary Markdown links in prose.
